# YouTube Video Manager

A simple Python project that uses SQLite to manage YouTube video records.

## Features
- Add new videos
- View all videos
- Update video details
- Delete videos
- Store video records in an SQLite database

## Technologies Used
- Python
- SQLite
- SQL

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

   `python youtube_manager.py`

## Learning Objectives
- Understand Python functions and loops
- Practice CRUD operations
- Execute SQL queries using Python
- Connect Python applications to an SQLite database
